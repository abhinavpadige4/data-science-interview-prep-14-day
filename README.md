## Daily Study Plan Overview

### Week 1: Foundations
- **Day 1**: Arrays & Strings, Descriptive Statistics, End-to-end ML Pipeline
- **Day 2**: Two pointers & Sliding window, Probability basics, Data preprocessing
- **Day 3**: Sorting & Searching, Discrete distributions, Model selection
- **Day 4**: Hash tables, Continuous distributions, Classification metrics
- **Day 5**: Linked lists, Hypothesis testing, Regression metrics
- **Day 6**: Stacks & Queues, Confidence intervals, Imbalanced data
- **Day 7**: Trees, Type I/II errors, Feature engineering

### Week 2: Advanced Topics
- **Day 8**: Heaps, Correlation vs causation, Model deployment
- **Day 9**: Graphs basics, Simple linear regression, Model monitoring
- **Day 10**: Dynamic Programming intro, Multiple linear regression, A/B testing
- **Day 11**: More DP, Logistic regression, Experiment tracking
- **Day 12**: Review weak areas, mixed practice, end-to-end case study
- **Day 13**: Full-length mock technical interview, review feedback
- **Day 14**: Light review, behavioral final prep, relaxation
