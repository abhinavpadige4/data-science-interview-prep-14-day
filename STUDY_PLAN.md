# 14-Day Data Science Interview Preparation Plan

## Overview
This plan covers Python, statistics, machine learning, and SQL fundamentals with daily LeetCode-style practice problems. Each day includes:
- 1.5 hours theory/study
- 1 hour practice problem solving
- 0.5 hours review and solution push to GitHub

## Day-by-Day Breakdown

### **Day 1: Python Basics & Arrays**
**Theory Focus**: Python syntax, data types, control flow, functions, arrays/lists
**Resources**:
- [Python Tutorial - Control Flow](https://docs.python.org/3/tutorial/controlflow.html)
- [Python Tutorial - Data Structures](https://docs.python.org/3/tutorial/datastructures.html)
- [Learn Python - Basics](https://www.learnpython.org/)
**Practice Problems**:
1. [Two Sum](https://leetcode.com/problems/two-sum/) - Find two numbers that add up to target
2. [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/) - Check if array contains duplicates

### **Day 2: NumPy Fundamentals**
**Theory Focus**: NumPy arrays, vectorized operations, broadcasting, basic statistics
**Resources**:
- [NumPy Quickstart Tutorial](https://numpy.org/doc/stable/user/quickstart.html)
- [W3Schools NumPy Tutorial](https://www.w3schools.com/python/numpy/default.asp)
**Practice Problems**:
1. [Plus One](https://leetcode.com/problems/plus-one/) - Increment large number represented as array
2. [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/) - Merge two sorted arrays

### **Day 3: pandas Essentials**
**Theory Focus**: DataFrames, Series, data loading, basic operations, filtering, grouping
**Resources**:
- [pandas 10 Minutes to pandas](https://pandas.pydata.org/docs/getting_started/10min.html)
- [pandas Intro Tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/06_calculate_statistics.html)
**Practice Problems**:
1. [Max Consecutive Ones](https://leetcode.com/problems/max-consecutive-ones/) - Longest sequence of 1s
2. [Find All Numbers Disappeared in Array](https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/) - Find missing numbers

### **Day 4: Statistics - Descriptive & Probability**
**Theory Focus**: Mean, median, mode, variance, standard deviation, probability basics, distributions
**Resources**:
- [Khan Academy - Descriptive Statistics](https://www.khanacademy.org/math/statistics-probability/summarizing-quantitative-data)
- [Statistics How To - Descriptive Stats](https://www.statisticshowto.com/probability-and-statistics/descriptive-statistics/)
**Practice Problems**:
1. [Intersection of Two Arrays](https://leetcode.com/problems/intersection-of-two-arrays/) - Find common elements
2. [Valid Anagram](https://leetcode.com/problems/valid-anagram/) - Check if strings are anagrams

### **Day 5: Statistics - Inferential**
**Theory Focus**: Hypothesis testing, confidence intervals, p-values, t-tests, chi-square
**Resources**:
- [Khan Academy - Hypothesis Testing](https://www.khanacademy.org/math/statistics-probability/significance-tests)
- [StatQuest - Hypothesis Testing](https://www.youtube.com/watch?v=HvDqbzuoo60)
**Practice Problems**:
1. [Two Sum II - Input Array Is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/) - Two sum with sorted array
2. [3Sum](https://leetcode.com/problems/3sum/) - Find triplets that sum to zero

### **Day 6: SQL Basics**
**Theory Focus**: SELECT, WHERE, GROUP BY, ORDER BY, basic joins, aggregation functions
**Resources**:
- [LeetCode SQL Tutorial](https://leetcode.com/studyplan/top-sql-50/)
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/)
**Practice Problems**:
1. [Recyclable and Low Fat Products](https://leetcode.com/problems/recyclable-and-low-fat-products/) - Simple WHERE filtering
2. [Customer Placing the Largest Number of Orders](https://leetcode.com/problems/customer-placing-the-largest-number-of-orders/) - GROUP BY and ORDER BY

### **Day 7: SQL Intermediate**
**Theory Focus**: JOINs (INNER, LEFT, RIGHT), subqueries, string functions, date functions
**Resources**:
- [SQL Joins Tutorial](https://www.w3schools.com/sql/sql_join.asp)
- [LeetCode SQL Practice](https://leetcode.com/problemset/database/)
**Practice Problems**:
1. [Combine Two Tables](https://leetcode.com/problems/combine-two-tables/) - LEFT JOIN practice
2. [Duplicate Emails](https://leetcode.com/problems/duplicate-emails/) - GROUP BY with HAVING

### **Day 8: Machine Learning - Supervised Learning**
**Theory Focus**: Linear regression, logistic regression, decision trees, model evaluation
**Resources**:
- [Scikit-learn Tutorial](https://scikit-learn.org/stable/tutorial/basic/tutorial.html)
- [Andrew Ng's ML Course (Coursera)](https://www.coursera.org/learn/machine-learning)
**Practice Problems**:
1. [Best Time to Buy and Sell Stock](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) - Single transaction profit
2. [Best Time to Buy and Sell Stock II](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/) - Multiple transactions

### **Day 9: Machine Learning - Unsupervised Learning**
**Theory Focus**: Clustering (K-means), dimensionality reduction (PCA), association rules
**Resources**:
- [Scikit-learn Clustering](https://scikit-learn.org/stable/modules/clustering.html)
- [StatQuest - K-means Clustering](https://www.youtube.com/watch?v=4b5d3muuQmA)
**Practice Problems**:
1. [Container With Most Water](https://leetcode.com/problems/container-with-most-water/) - Max area problem
2. [Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/) - Water trapping algorithm

### **Day 10: Machine Learning - Model Evaluation**
**Theory Focus**: Overfitting/underfitting, bias-variance tradeoff, cross-validation, metrics (accuracy, precision, recall, F1, ROC-AUC)
**Resources**:
- [Scikit-learn Model Evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)
- [ML Metrics Explained](https://developers.google.com/machine-learning/crash-course/classification/precision-and-recall)
**Practice Problems**:
1. [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) - Kadane's algorithm
2. [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) - Array division problem

### **Day 11: Python for Data Science - Advanced**
**Theory Focus**: List comprehensions, lambda functions, map/filter/reduce, error handling, modules
**Resources**:
- [Python Functional Programming](https://docs.python.org/3/howto/functional.html)
- [Real Python - List Comprehensions](https://realpython.com/list-comprehension-python/)
**Practice Problems**:
1. [Valid Parentheses](https://leetcode.com/problems/valid-parentheses/) - Stack-based validation
2. [Implement Queue using Stacks](https://leetcode.com/problems/implement-queue-using-stacks/) - Data structure implementation

### **Day 12: End-to-End Data Science Workflow**
**Theory Focus**: Data cleaning, feature engineering, model selection, deployment basics
**Resources**:
- [CRISP-DM Methodology](https://www.datascience-pm.com/crisp-dm-2/)
- [Kaggle Learn - Data Science](https://www.kaggle.com/learn)
**Practice Problems**:
1. [Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/) - Tree traversal
2. [Invert Binary Tree](https://leetcode.com/problems/invert-binary-tree/) - Tree manipulation

### **Day 13: Comprehensive Review & Mock Interview**
**Theory Focus**: Weak area identification, speed practice, interview strategies
**Resources**:
- [LeetCode Explore - Data Science](https://leetcode.com/explore/learn/card/data-science/)
- [Interview Cake - Data Science](https://www.interviewcake.com/data-science-interview-questions)
**Practice Problems**:
1. [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/) - Heap/quickselect
2. [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/) - Hash map + heap

### **Day 14: Final Preparation & Relaxation**
**Theory Focus**: Light review, behavioral prep, confidence building
**Resources**:
- [Glassdoor Data Science Interview Questions](https://www.glassdoor.com/Interview/data-scientist-interview-questions-SRCH_KO0,14.htm)
- [Towards Data Science - Interview Tips](https://towardsdatascience.com/how-to-crush-your-data-science-interview-1b3079d3660)
**Practice Problems**:
1. [Binary Search](https://leetcode.com/problems/binary-search/) - Classic binary search
2. [Valid Sudoku](https://leetcode.com/problems/valid-sudoku/) - Constraint validation

## How to Use This Plan
1. Each day, study the theory resources for 1.5 hours
2. Solve the 2 practice problems for 1 hour
3. Write clean, commented Python solutions
4. Push solutions to the `solutions/` directory
5. Update your progress in the tracking table above
6. Review and refine solutions for 0.5 hours

## Solution Naming Convention
- `0001_two_sum.py` - Problem number, descriptive name
- All solutions include:
  - Problem description as comment
  - Clean, efficient Python code
  - Time and space complexity analysis
  - Brief explanation of approach
